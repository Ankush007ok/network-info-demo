Network details sharing demo

This page demonstrates how a website can request permission to share basic network information with its owner.

If you choose to agree, this page will:
  • Request your public IP address from an IP lookup service.
  • Retrieve approximate city/region/country and ISP, if available.
  • Send those details to the page owner's private Supabase database.

This is not your precise GPS location. IP-based location can be inaccurate. The page does not make the lookup or send anything until you press the consent button below. Do not agree unless you understand and accept this.

You can close this page without sharing anything. No account sign-in is required.
